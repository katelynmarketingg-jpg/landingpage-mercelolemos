# Imagens da landing page

Coloque os arquivos de imagem **nesta pasta**, com **exatamente estes nomes**,
para que apareçam automaticamente no site. Enquanto os arquivos não existirem, o
site mostra um fallback elegante (arte em linha dourada), sem quebrar.

| Nome do arquivo   | Onde aparece                           | Formato ideal              |
| ----------------- | -------------------------------------- | -------------------------- |
| `hero-bg.jpg`     | Fundo do topo (hero), opacidade baixa  | horizontal, ~1920px        |
| `retrato.jpg`     | Foto do Marcelo (Apresentação)         | vertical 4:5, ~1000px      |
| `livro-1.jpg`     | Capa do livro "Direito Penal e Hermenêutica" (Obras) | vertical 3:4, ~900px |
| `livro-2.jpg`     | Capa do livro "Ações Neutras em Direito Penal" (Obras) | vertical 3:4, ~900px |

Sugestão: a foto dos **prédios** (preto e branco) fica ótima no hero — ela
entra com opacidade baixa e em tons de cinza, como textura de fundo, sem
atrapalhar a leitura do texto.

> Dica: dá para arrastar e soltar os arquivos direto aqui pelo GitHub
> ("Add file" → "Upload files"), mantendo os nomes acima.
